## 最终参数配置表

```json
{
  "height":  { "kp": 90.0, "ki": 1.0 },
  "landing": {
    "descent_rate_m_s": 0.3,
    "touchdown_max_vz_m_s": 0.3,
    "flare_clearance_m": 0.15,
    "flare_rate_m_s": 0.2,
    "settling_vertical_speed_limit_m_s": 0.15,
    "settling_time_s": 0.35
  }
}
```

| 参数 | 值 | 作用（来自 Task 12/13 结论） |
|---|---|---|
| `height.kp` / `height.ki` | 90.0 / 1.0 | 消除纯 PD 悬停下垂（-0.073m → -0.033m），稳定时间 ~1.6s |
| `landing.descent_rate_m_s` | 0.3 | 低速下降剖面，触地 vz ~-0.035 m/s |
| `landing.touchdown_max_vz_m_s` | 0.3 | 触地速度上限（安全边界 0.35 m/s 内） |
| `landing.flare_clearance_m` | 0.15 | 低拉平高度，配合高 flare_rate 快速降速 |
| `landing.flare_rate_m_s` | 0.2 | 拉平段减速，强扰动下确认 LANDED |
| `landing.settling_vertical_speed_limit_m_s` | 0.15 | 着水稳定判定速度限 |
| `landing.settling_time_s` | 0.35 | 着水稳定确认时长（SPOOL_DOWN 前置） |
