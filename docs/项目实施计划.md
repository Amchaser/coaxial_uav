# 共轴无人机水上起降控制关键技术研究：实施计划

## 1. 项目定位与范围

项目目标是在 Gazebo 中构建**静水面、非 CFD**的共轴无人机水上起降闭环仿真，完成水面起飞、低空悬停、定点自主降落及批量验证。

纳入范围：共轴双旋翼机体与浮筒/起落架模型、静水视觉与接触、水面附近简化扰动、旋翼推力与电机模型、PID 控制器、起降状态机、可视化、日志和批量测试。

不纳入范围：流体力学或波浪耦合、硬件改装与实飞、复杂控制算法（如 MPC 或自适应控制）自研。

## 2. 验收目标

| 项目 | 建议指标 |
| --- | ---: |
| 起飞成功率 | ≥ 95% |
| 低空悬停时长 | ≥ 60 s |
| 悬停高度误差 | ≤ ±0.15 m |
| 最大滚转/俯仰角 | ≤ 5° |
| 定点落水位置误差 | ≤ 0.30 m |
| 触水垂直速度 | ≤ 0.20 m/s |
| 触水后侧翻 | 0 次 |

## 3. 总体技术路线

```text
参数核验与模型标定
        ↓
Gazebo 静水场景 + 共轴机体 + 浮筒接触
        ↓
电机/旋翼推力模型 + 控制分配
        ↓
姿态环 PID → 高度环 PID
        ↓
起飞状态机 → 悬停保持 → 分段降落状态机
        ↓
批量测试、数据统计、视频与报告
```

控制器采用“姿态内环 + 高度外环”。控制分配应提供总推力、滚转、俯仰、偏航四个虚拟输入。

> 约束：上下两个同轴旋翼仅靠转速差无法独立产生滚转、俯仰和偏航控制力矩。因此仿真模型应包含倾斜盘/旋翼倾转等姿态执行机构，或清晰定义等效的虚拟执行机构；不能把双电机差速直接当作完整三轴姿态控制。

## 4. 分阶段实施

### 阶段 1：环境与参数基线（第 1 周）

- 确定 Gazebo、ROS 2 和控制接口版本。
- 建立目录结构、参数配置和日志规范。
- 录入已有文档的质量、惯量、旋翼尺寸和动力参数。
- 标定推力—转速模型；最大总推力至少应达到重量的 1.5 倍后，才进入 PID 调参。

产物：环境基线、参数配置文件、推力标定计算记录。

### 阶段 2：场景与模型（第 2–3 周）

- 建立机身、上/下旋翼、浮筒或防倾覆起落架。
- 建立静态水面视觉和碰撞平面；以接触阻尼、摩擦模拟触水，不做真实流体耦合。
- 配置高度、速度、姿态角、角速度、旋翼转速、控制输出等可视化数据。

产物：可在水面稳定静置并输出状态的 Gazebo 场景。

### 阶段 3：动力学与悬停闭环（第 4–5 周）

- 建立一阶电机模型与旋翼推力/反扭矩模型。
- 验证上下旋翼反向旋转及悬停偏航平衡。
- 按“姿态内环、再高度外环”的顺序整定 PID。
- 在无扰动和轻微可重复扰动下验证悬停。

产物：稳定悬停演示、PID 参数文件和响应曲线。

### 阶段 4：水面起飞（第 6 周）

状态机：`IDLE → ARM → SPOOL_UP → TAKEOFF → CLIMB → HOVER`。

- 电机平滑升速，限制起飞初期姿态积分项。
- 离水后爬升至 1.5–2.0 m，再切入定高悬停。
- 测试零偏差、轻微倾斜和横向偏移初始条件。

产物：起飞视频、时序图与测试记录。

### 阶段 5：低空悬停与抗扰（第 7 周）

- 在 1.0–2.0 m 高度连续悬停至少 60 s。
- 注入小幅、可复现实验扰动，比较 PID 参数组合。
- 优化高度超调、姿态振荡、漂移和电机输出抖动。

产物：最优参数表和扰动对比图。

### 阶段 6：分段定点降落（第 8–9 周）

状态机：`高位悬停 → 归位对准 → 缓速下降 → 近水缓冲 → 触水确认 → 电机怠速/停机`。

初始建议值：高位悬停 1.5–2.0 m；常规下降 0.3–0.5 m/s；近水切换 0.3–0.5 m；近水下降 0.1–0.2 m/s。触水由高度、垂直速度与接触信号联合判定。

产物：完整降落演示、触水速度和落点误差数据。

### 阶段 7：批量测试与成果整理（第 10–12 周）

- 变量：横向初始偏移（0、0.2、0.5 m）、偏航误差（0°、5°、10°）、扰动强度（无、弱、中）。
- 每组重复不少于 10 次，统计成功率、最大姿态偏差、高度误差、落点误差和触水速度。

产物：Gazebo 工程、配置文件、CSV 数据与图表、演示视频、实验报告和技术总结。

## 5. 工程结构

```text
coaxial_uav/
├── config/       # 模型、动力学、PID 与测试参数
├── controllers/  # PID、控制分配和起降状态机
├── data/         # 原始日志与统计结果
├── docs/         # 计划、工作日志、报告
├── launch/       # 启动文件
├── models/       # SDF 模型
├── scripts/      # 批量测试、绘图与录制脚本
├── videos/       # 演示素材
└── worlds/       # Gazebo 世界文件
```

## 6. 当前关键风险与处理顺序

已有资料中的 `kT = 1.53e-3 N/(rad/s)^2`、最大转速 `167 rad/s` 和质量 `8.2 kg` 组合后，推重比仅约为 1.062，推力余量约 6.2%，不满足起飞和抗扰需求。阶段 1 必须先统一推力系数、空气密度处理方式及最大转速口径，并使推重比达到至少 1.5；之后再进行控制器调参。
